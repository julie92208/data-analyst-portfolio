Global Healthcare Workforce Analysis

Tableau Dashboard · WHO Global Health Observatory Dataset

Project Overview

This project analyzes global doctor and nurse workforce distribution using real-world data from the WHO Global Health Observatory (GHO). The dataset includes 194 countries and covers healthcare workforce trends from 2010–2023. I used Python to clean and prepare the data, then visualized the insights through an interactive Tableau dashboard.

Dataset Source

Data retrieved from the WHO Global Health Observatory (GHO) – National Health Workforce Accounts (NHWA).
🔗 WHO Health Workforce Dataset

Data Processing (Python)

I used Python (Pandas & Jupyter Notebook) to merge, clean, and transform the two main files:

  • data-doctor.csv – Doctors per 10,000 population
  • data-nurse.csv – Nurses & midwives per 10,000 population
  • Created Nurse_to_Doctor_Ratio as the key metric for analysis

Key Insights

  • Divergent Trends (2010–2020): Some regions show widening gaps between nurse and doctor counts.
  • Regional Disparity: Africa has the highest nurse-to-doctor ratios globally, showing structural workforce imbalance.
  • Top 5 Countries: Highest ratios appear mainly in Africa and the Eastern Mediterranean region.
  • Canada (2018–2023): Nurses grew rapidly while doctor growth remained modest.
  • Global Correlation: Countries with more doctors also tend to have more nurses — a strong positive relationship.
